# エッグスシミュ (Eggscalibur Simulator)
『Backpack Battles』配置検証シミュレーター ＆ スコアアタックツール

ゲーム『Backpack Battles』における「エッグスカリバー」＋「食べ物（トウガラシ/バナナ/カップケーキ）」＋「マナオーブ」を中心とした、50秒間での最大ヒート蓄積効率を検証・競い合うWebアプリケーションです。

## 🌟 主な機能と特徴

### 1. 忠実な9×7バックパック盤面
- **サイズ**: 実際のゲームと同じ **横9×縦7（全63マス）**。
- **2つの盤面モード**:
  - **モードA（全解放モード）**: バッグ制限なしで63マスすべてに自由に配置可能。
  - **モードB（バッグ構築モード）**: 盤面にバッグタイル（革のカバン、ウエストポーチ、スタミナバッグ）を配置して枠を作る本編同様のモード。
- **直感的な操作性**:
  - アイテムをドラッグ＆ドロップで配置・移動。
  - **ドラッグ中に右クリック（またはRキー）で右に90度回転**。
  - **キーボード十字キー（↑↓←→）で全アイテムの一括移動**（盤面外にはみ出る移動は無反応で安全保護）。
  - **Tabキー**で「アイテム移動」と「バッグ移動」の即時切り替え。
  - **🗑️ ゴミ箱エリアへドラッグ＆ドロップで個別削除**、または「全削除」ボタンで一括クリア。

### 2. 登場アイテムとシナジー仕様
- **🍳 エッグスカリバー（曲がった4マス / 武器）**:
  - クールダウン: 1.6秒 / スタミナ消費: 1.3
  - **スタミナ不足ペナルティ**: スタミナが1.3未満の場合、攻撃が失敗しクールダウンが0から再スタート。
  - **マナ消費連鎖**: マナが11以上ある場合、11マナを消費して**★スロットにあるすべての食べ物をクールダウン進捗を維持したまま一斉強制起動**！
- **🌶️ トウガラシ（2マス / 食べ物）**:
  - クールダウン: 4.5秒 / 1ヒートを獲得。
- **🍌 バナナ（曲がった3マス L字 / 食べ物）**:
  - クールダウン: 5.0秒 / スタミナを1回復。
- **🧁 カップケーキ（1マス / 食べ物）**:
  - クールダウン: 6.0秒 / 一番多いバフ2を獲得（最多バフが同数の場合はマナ2を獲得）。
- **🥗 食べ物共通シナジー（隣接異種加速）**:
  - 自身と**種類の異なる食べ物**と隣接（8近傍：縦横斜め）している場合、その**アイテム個数×10%** のCD加速（加算方式）を獲得。
- **🔮 マナオーブ（1マス / アクセサリー）**:
  - **パッシブ発動**: ★スロットにあるアイテムが発動した時、**2回に1回1マナを獲得**（奇数回はなし、偶数回で獲得）。
  - **マナオーブ覚醒**: 累計35マナ到達時に即座に35マナを消費して**マナ以外の全バフを各3獲得（1回のみ発動）**。
- **👝 ウエストポーチ（2マス / バッグ）**:
  - 乗っているアイテムのクールダウンを1マスにつき10%加速（複数マス乗れば重複）。
- **🧳 スタミナバッグ（縦3マス / バッグ）**:
  - 最大スタミナおよび初期スタミナが+1。

### 3. 50秒間動的戦闘シミュレーション
- **総合加速計算（加算方式）**:
  $$\text{速度倍率} = 1.0 + (\text{ヒート数} \times 0.02) + (\text{ウエストポーチマス数} \times 0.10) + (\text{隣接する異なる食べ物数} \times 0.10)$$
- **跳ねる演出（Bounce）**: アイテムが発動した際、視覚的にポンと跳ねるアニメーション演出を搭載。
- **リアルタイムグラフ**: 秒間ヒート上昇曲線をCanvasでリアルタイム描画。
- **即時計算モード**: 50秒間の戦闘を一瞬で計算し、結果・グラフ・ログを即座に表示。

### 4. 設問（パターン1, 2, 3...）設定機能
- 設問ごとに「盤面モード（全解放/バッグ）」「アイテム配置上限」「バッグ個数制限」を設定可能。
- 画面上部の「⚙️ 設問設定・新規作成」から、新しいパターン（課題）の追加や編集、JSONインポート/エクスポートが可能。

### 5. リーダーボード（スコアアタック & 管理機能）
- 設問ごとにスコア（50秒後のヒート数、到達マナ、スタミナ不足回数、配置データ）を保存・ランキング表示。
- **タイブレーク規則**: 同率スコアの場合は**先に登録したプレイヤーが1位、後から登録したプレイヤーが2位（先着順）**。
- **👑 1位の配置を復元**: ボタンを1クリックするだけで、1位のプレイヤーの配置が盤面にそのまま復元。
- **管理者保護モード**: 管理者認証を行うと、個別スコアの削除ボタン（🗑️）が利用可能。
- **Firebase Firestore 連携対応（世界リアルタイム同期）**:
  - `js/firebase-config.js` に設定を入力することで、オンラインリアルタイムランキングに即時移行可能。
  - 未設定時は自動的にブラウザローカル保存モード（localStorage）で動作し、UI上の「⚠️ ローカル保存中」バッジからワンクリックで設定案内を確認できます。

#### 🌐 世界リアルタイム同期の有効化手順（無料・所要3分）
1. **Firebase プロジェクト作成**:
   - [Firebase Console](https://console.firebase.google.com/) にアクセスし、「プロジェクトを追加」（無料のSparkプラン・クレカ不要）。
2. **Cloud Firestore データベース作成**:
   - 左メニュー「構築」→「Firestore Database」→「データベースの作成」。
   - セキュリティルールは「**テストモードで開始**」を選択し、ロケーションは「`asia-northeast1` (東京)」などを選択。
3. **セキュリティルールの設定**:
   - 「Firestore Database」→「ルール」タブを開き、以下のように設定して「公開」をクリック：
   ```javascript
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /leaderboard/{challengeId}/scores/{scoreId} {
         allow read, write: if true;
       }
     }
   }
   ```
4. **Webアプリ設定の反映**:
   - プロジェクト設定（歯車アイコン）→「マイアプリ」の「ウェブ（`</>`）」アイコンをクリックしてアプリを登録。
   - 表示された `firebaseConfig`（apiKey, projectId 等）を `js/firebase-config.js` の `window.FIREBASE_CONFIG` に貼り付けます。
5. **公開**:
   - 変更をGitHubへPushすれば、GitHub Pages上で世界同期リーダーボードが即座に稼働します！
